## Description

```
busy 在 Windows 11 任务栏中实时显示 CPU、内存、GPU、网络、磁盘、电池和温度读数，位于通知区域旁边或任务栏左边缘。单击读数即可打开详细的浮出窗口。

任务栏中的读数
每个读数可以显示为文本、图形、条形，或（网络和磁盘）读取/写入速率；可以使用自己的颜色或按负载着色，可以显示或隐藏标签，并按各自的间隔更新。将鼠标悬停在读数上可查看其数值。放不下的读数会被省略，而不会遮挡任务栏按钮。支持水平和垂直任务栏。

每个读数都有浮出窗口
单击读数可查看最近几分钟（1 到 10 分钟，可在“设置”中设定）的图表和详细信息：
CPU：系统、用户和空闲时间，每个逻辑处理器，速度、温度、进程、线程、句柄、正常运行时间。
内存：使用中、已修改、备用和空闲，已提交、已压缩、分页和非分页缓冲池。
GPU：占用最高的引擎，专用和共享内存，温度、功率、风扇、频率、驱动程序和 DirectX 版本。
磁盘：卷和可用空间、响应时间、温度、读取和写入的字节数。
网络：接口、WLAN 频段和信号、地址、发送和接收总量。
电池：剩余时间、功耗、健康度、循环次数。
传感器：所有温度，以及传感器工具提供的风扇、功率和电压。
CPU、内存、GPU 和磁盘会列出占用最高的进程。每个浮出窗口都链接到任务管理器和该读数的设置。

设置
Windows 11 风格的设置，支持搜索、键盘导航、屏幕阅读器、每个读数的实时预览，以及跟随 Windows 或手动设置的浅色和深色主题。更改立即生效。右键单击读数可打开“设置”、“在任务栏上显示”、“位置”和“退出”。首次启动时的简短设置向导可让你选择读数和任务栏的一侧。

温度
GPU 温度在 NVIDIA 和 AMD 显卡以及任何 WDDM 2.5 或更高版本的驱动程序上开箱即用。CPU 温度、风扇和 CPU 功率来自 LibreHardwareMonitor 或 HWiNFO：需要运行其中之一，并打开“设置”中的“高级”>“第三方传感器工具”（默认关闭）。

隐私且轻量
busy 不收集任何数据；从 Microsoft Store 安装时不发出任何网络请求。它无需管理员权限，也无需驱动程序，并会在屏幕锁定或关闭时暂停。原生 Win32 和 Direct2D，只有一个小巧的可执行文件。

busy 是基于 MIT 许可证的开源软件。

需要 Windows 11 23H2（版本 22631）或更高版本，x64。
```
