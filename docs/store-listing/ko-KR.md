## Description

```
busy는 CPU, 메모리, GPU, 네트워크, 디스크, 배터리, 온도 측정값을 Windows 11 작업 표시줄의 알림 영역 옆이나 작업 표시줄 왼쪽 끝에 실시간으로 표시합니다. 측정값을 클릭하면 자세한 플라이아웃이 열립니다.

작업 표시줄의 측정값
각 측정값은 텍스트, 그래프, 막대 또는 (네트워크와 디스크는) 읽기/쓰기 속도로 표시되며, 고유한 색이나 부하에 따른 색으로, 레이블을 표시하거나 숨긴 채, 각자의 간격으로 업데이트됩니다. 마우스를 올리면 값이 표시됩니다. 공간이 부족한 측정값은 작업 단추를 가리지 않고 생략됩니다. 작업 표시줄은 가로든 세로든 상관없습니다.

측정값마다 플라이아웃
측정값을 클릭하면 최근 몇 분(설정에서 1~10분)의 차트와 세부 정보가 표시됩니다.
CPU: 시스템, 사용자, 유휴 시간, 모든 논리 프로세서, 속도, 온도, 프로세스, 스레드, 핸들, 작동 시간.
메모리: 사용 중, 수정됨, 대기 중, 여유, 커밋됨, 압축됨, 페이징 풀과 비페이징 풀.
GPU: 가장 바쁜 엔진, 전용 메모리와 공유 메모리, 온도, 전력, 팬, 클럭, 드라이버와 DirectX 버전.
디스크: 볼륨과 여유 공간, 응답 시간, 온도, 읽고 쓴 바이트.
네트워크: 인터페이스, Wi-Fi 대역과 신호, 주소, 보내고 받은 총량.
배터리: 남은 시간, 소비 전력, 성능 상태, 사이클 수.
센서: 모든 온도와, 센서 도구가 제공하는 경우 팬, 전력, 전압.
CPU, 메모리, GPU, 디스크는 리소스를 가장 많이 쓰는 프로세스를 보여 줍니다. 모든 플라이아웃에서 작업 관리자와 해당 측정값의 설정을 열 수 있습니다.

설정
Windows 11 스타일의 설정으로 검색, 키보드 탐색, 화면 읽기 프로그램 지원, 측정값마다 실시간 미리 보기를 제공하며, 밝은 테마와 어두운 테마는 Windows를 따르거나 직접 지정할 수 있습니다. 변경 내용은 바로 적용됩니다. 측정값을 마우스 오른쪽 단추로 클릭하면 설정, 작업 표시줄에 표시, 위치, 종료 메뉴가 나타납니다. 처음 시작할 때 짧은 초기 설정에서 측정값과 작업 표시줄의 위치를 고를 수 있습니다.

온도
GPU 온도는 NVIDIA 및 AMD 그래픽과 WDDM 2.5 이상의 모든 드라이버에서 별도 설정 없이 표시됩니다. CPU 온도, 팬, CPU 전력은 LibreHardwareMonitor 또는 HWiNFO를 실행하고 설정 > 고급 > 타사 센서 도구를 켜면(기본값은 꺼짐) 해당 프로그램에서 가져옵니다.

개인 정보 보호와 가벼움
busy는 아무것도 수집하지 않으며, Microsoft Store에서 설치한 경우 네트워크 요청을 전혀 하지 않습니다. 관리자 권한이나 드라이버가 필요 없고, 화면이 잠기거나 꺼져 있는 동안에는 일시 중지됩니다. 네이티브 Win32와 Direct2D로 만든 작은 실행 파일 하나입니다.

busy는 MIT 라이선스에 따른 오픈 소스입니다.

Windows 11 23H2(빌드 22631) 이상, x64가 필요합니다.
```
